# EPLAN AI 商机洞察看板 · 演示版

中项网 × EPLAN 商机洞察服务售前演示。数据源自重点客户监测实样（3家订阅企业、111条线索：参与项目36 / 招投标54 / 近期资讯21，另有3张P1示例卡用于展示P1触达形态）。

**在线演示**：https://dream00neal-ui.github.io/eplan-ai-insight-demo/

## 功能一览

- **KPI概览**：监测客户数、线索总数、P1/P2/P3分布、近30天新增（可点击直达对应内容）
- **按客户聚合视图**：左侧企业订阅监控列表（可搜索、可自助添加），右侧企业横幅 + 线索卡片时间线
- **线索卡片四要素**：触发事件 / 双时间（发生+采集）/ AI相关性说明 / 证据溯源链接，另含建议跟进动作与已读·跟进中·忽略状态标记
- **详情页**：点击卡片标题查看事件原文全文、完整元数据、相关性与建议动作
- **多维度筛选**：信源（参与项目/招投标/近期资讯）× 等级（P1/P2/P3）× 关键词检索，可组合
- **推送机制演示**：日报/P1即时提醒双层推送样式
- **P1/P2/P3分级规则**：评分口径说明（客户匹配度 × 事件强度 × 时效性）

## 使用方式

单文件纯静态页面（`index.html`），浏览器直接打开即可，无需部署、无外部依赖。
